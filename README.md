# KeyHeat

키 입력을 화면에 팝업으로 표시하는 Windows 애플리케이션입니다.

## 계획

1. **팝업 효과 옵션**
   - 이동(위로 떠오름), 회전, 아웃라인, 그림자
   - 가독성과 연출 품질 상승
2. **지속시간/크기 랜덤 범위**
   - 예: 0.8~1.6초, 크기 ±20%
   - 화면이 더 자연스럽게 보임
3. **키 필터**
   - 특정 키 제외(Shift/Ctrl/Alt 등)
   - 조합키만 표시(Ctrl+C 같은 형태)
4. **출력 모드**
   - 단일 모니터 / 모든 모니터 랜덤 / 현재 활성 창 모니터
   - 멀티모니터 활용도 증가
5. **프로필 저장**
   - Gaming / Work / Stream 프리셋
   - 클릭 한 번으로 설정 전환
6. **트레이 아이콘**
   - 백그라운드 실행 + 빠른 ON/OFF
   - 사용성 크게 개선
